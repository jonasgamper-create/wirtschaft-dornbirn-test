Sechs präsentierbare Entwürfe im verifizierten Instagram-CI von @wirtschaft_dornbirn:

- Schwarz-Weiß-Fotografie
- Senf-/Gold-Akzent
- Helvetica-/Grotesk-Typografie in Kleinschreibung
